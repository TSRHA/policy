# 台灣海洋永續休閒採捕政策白皮書

Docusaurus site for a policy white paper draft on sustainable recreational marine harvesting in Taiwan.

## Local development

```bash
npm install
npm run start
```

## Build

```bash
npm run build
```

Cloudflare Pages build settings:

- Build command: `npm run build`
- Build output directory: `build`
- Node.js: 18+

## Evidence discipline

- Do not use unverified draft text as a final policy claim.
- Keep source URLs, dates, document numbers, page numbers, and short quotations in `docs/appendix/references.md`.
- International numeric limits are precedents, not direct Taiwan recommendations.
