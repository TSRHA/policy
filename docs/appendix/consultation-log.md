# 諮詢紀錄（草稿）

## 目前狀態

本版本諮詢進行中，包括外部專家、政府機關或利害關係人正式諮詢。以下為建議諮詢架構與待詢問題，後續每次座談、專家審查將紀錄於此。

## 建議諮詢對象

| 類別 | 對象 | 主要問題 |
|---|---|---|
| 政府機關 | 海洋委員會／海保署、農業部漁業署、地方政府漁業／農業單位 | 法源、行政可行性、地方公告程序、海保法接口 |
| 科學專家 | 魚類生態、漁業資源、珊瑚礁生態、社會科學研究者 | 指標魚種、體長資料、風險矩陣、監測設計 |
| 利害關係人 | 魚槍／自潛採捕者、釣客、漁會、潛水業者、保育團體 | 規範可接受性、回報誘因、公平性、場域衝突 |
| 原住民族與地方社群 | 部落代表、地方治理組織 | 傳統利用、共同治理、資料主權 |
