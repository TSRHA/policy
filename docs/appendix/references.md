# 參考文獻與來源驗證紀錄（草稿）

本附錄列出白皮書目前使用或建議使用的主要來源。驗證狀態分為：

- **已連線驗證：** 草稿製作時以 HTTP/HTTPS 連線確認來源可存取或 DOI 可解析。
- **需人工補件：** 來源存在於研究報告或地方公告描述中，但白皮書定稿前應下載 PDF、保存快照、標頁碼與文號。
- **待查證：** 尚未取得原文，不得作為定稿主張唯一依據。
