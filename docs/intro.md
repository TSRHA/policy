# 台灣海洋永續休閒採捕政策白皮書（beta 版）

本白皮書由台灣海洋永續休閒採捕聯盟所建立，目的為提供給政府、地方主管機關、民間團體與休閒採捕社群討論的政策倡議方案。

## 核心政策問題

本白皮書不是主張放任或降低保育標準，而是建議政府以「魚種、體型、繁殖風險、採捕行為與資料回報」作為海洋休閒採捕管理核心，避免僅以「魚槍／魚叉」等工具名稱作為孤立禁令。更適當的政策方向是：

1. 將釣魚以外的合法休閒自用採捕納入「友善採捕」教育與資訊體系；
2. 對高風險行為（如水肺／空氣輔助採捕、夜間專獵、採捕大型繁殖主力個體）建立清楚規範；
3. 以自律準則、漁獲回報、公民科學與座談諮詢補足資料缺口；
4. 分階段試辦魚種別體長建議、上限／slot 與共同治理。
