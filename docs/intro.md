# 台灣海洋永續休閒採捕政策白皮書

本白皮書由台灣海洋永續休閒採捕聯盟所建立，目的為提供給政府、地方主管機關、民間團體與休閒採捕社群討論的政策倡議方案。

## 核心政策問題

本白皮書不是主張放任或降低保育標準，也不是為任何單一採捕工具辯護；它建議政府以「魚種、體型、繁殖風險、採捕行為與資料回報」作為海洋休閒採捕管理核心。釣竿、徒手採集、手網、潮間帶採集、自由潛水採捕、魚叉／魚槍等方式都可被納入比較，但主文焦點放在行為限制與制度設計，而非工具本身。更適當的政策方向是：

1. 將釣竿以外的合法休閒自用採捕納入「友善採捕」教育與資訊體系；
2. 對高風險行為（如水肺／空氣輔助採捕、夜間專獵、採捕大型繁殖主力個體、禁區或禁捕期採捕）建立清楚規範；
3. 以自律準則、漁獲／採集回報、公民科學與座談諮詢補足資料缺口；
4. 分階段試辦魚種別體長建議、尾數、上限／slot、場域分區與共同治理。
