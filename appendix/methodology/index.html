研究方法

1. 政策論證方法​

本白皮書採用政策文件而非純學術論文格式，但保留證據與引用紀律。核心論證鏈為：

事實 → 問題 → 原因 → 目標 → 選項 → 比較 → 建議 → 執行 → 評估。

每一項政策建議均應能回答：

  1. 要解決哪一個可驗證問題？
  2. 造成問題的制度原因是什麼？
  3. 有哪些可行政策選項？
  4. 為什麼建議方案比其他方案更相稱、有效、可行？
  5. 執行後如何監測與修正？

2. 證據蒐集方法​

已使用資料​

  • 研究報告：友善採捕・現況與問題、友善採捕・短中長期建議。
  • 台灣法規：全國法規資料庫與地方公告（待補完整快照）。
  • 官方政策白皮書：海洋委員會 2025 年《國家海洋政策白皮書》完整版 PDF，已下載並進行文字抽取、頁碼定位與關鍵詞檢索。
  • 新北市貢寮、萬里、瑞芳水產動植物繁殖保育區及有關限制事項公告草案 web.law.ntpc.gov.tw/news.aspx?msgid=7407。
  • 國際案例：美國、澳洲、帛琉、紐西蘭、地中海國家官方資料與法規。
  • 科學文獻：Froese 三指標、釣獲放流致死率、魚槍文獻回顧、ERAEF。

建議補強資料​

  • 地方政府草案原文、預告理由與會議紀錄。
  • 採捕者訪談與匿名漁獲日誌。
  • 水下視覺調查與指標魚種體長資料。
  • 保育團體、漁會、原住民族、潛水業者與地方政府座談紀錄。

3. 來源驗證流程​

  1. 優先取得法規原文、官方 PDF、DOI 或主管機關頁面。
  2. 保存查詢日期、URL、文號、條號、頁碼與原文短引。
  3. 對地方草案與社群轉述標示「待查證」，不得作為定稿唯一依據。
  4. 若來源網址失效，需保存 Internet Archive、官方快照或重新取得最新版本。
  5. 定稿前由至少一位非撰稿者進行逐項引用核對。

4. 座談會設計​

建議採半結構式諮詢：會前提供政策問題、初步證據、選項矩陣與待查證清單；會中分組討論保育目標、工具公平性、資料回報、地方場域、指標魚種；會後公開摘要與回應表，每一項意見列明採納、部分採納或不採納理由。

5. 實地調查設計​

  • 水下視覺樣線： 固定點、固定季節、記錄魚種與體長級距。
  • 採捕者日誌： 記錄實際採捕與「看見但未採」資訊，用於理解選擇性。
  • 釣竿放流觀察： 蒐集深度、鉤傷、氣壓傷與釋放狀態資料。
  • 地方規範盤點： 將各公告轉為可比較資料表。

6. 研究限制​

本白皮書不等同最終法規建議。所有數字型體長建議均應在取得本土魚種資料後才提出；目前只建議建立程序、指標魚種試辦與資料基礎。
