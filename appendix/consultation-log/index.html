諮詢紀錄

目前狀態​

本版本諮詢進行中，包括外部專家、政府機關或利害關係人正式諮詢。以下為建議諮詢架構與待詢問題，後續每次座談、專家審查將紀錄於此。

建議諮詢對象​

類別對象主要問題
政府機關海洋委員會／海保署、農業部漁業署、地方政府漁業／農業單位法源、行政可行性、地方公告程序、海保法接口
科學專家魚類生態、漁業資源、珊瑚礁生態、社會科學研究者指標魚種、體長資料、風險矩陣、監測設計
利害關係人休閒自用採捕者（釣客、徒手採集、手網、自由潛水採捕、魚叉／魚槍等）、漁會、潛水業者、保育團體規範可接受性、回報誘因、公平性、場域衝突
原住民族與地方社群部落代表、地方治理組織傳統利用、共同治理、資料主權

待詢核心問題​

  1. 政府若限制特定休閒採捕方式，具體保育目標是哪一魚種、棲地、季節或行為風險？
  2. 是否有比較釣竿、徒手採集、手網、自由潛水採捕、魚叉／魚槍、水肺／空氣輔助、夜間等不同方式與行為的證據？
  3. 對同一魚種與場域，採體長、尾數、季節、禁水肺、禁夜間、回報等替代方案，是否能達成相同或更佳保育效果？
  4. 哪些魚種適合作為第一階段指標魚種？
  5. 採捕者願意如何回報資料？需要何種匿名、地點模糊化或資料使用承諾？
  6. 地方政府需要何種中央指引，才能避免公告式工具名稱禁令？

Claude Code / Fable 諮詢建議提示​

若後續使用 Claude Code model 3 - Fable 逐章審閱，建議提供以下上下文，避免偏離主題：

  • 政策目標：政府應以生態目標與行為風險管理休閒漁獵／友善採捕；工具差異可以被管理，但主文不應成為任何單一採捕方式的辯護書。
  • 研究報告：
    • https://liumusicforever.github.io/friendly-harvest-research/index.html
    • https://liumusicforever.github.io/friendly-harvest-research/plan.html
  • 必守限制：地方草案與案例應作為附錄或治理風險例證，不要反覆置於主文中心；不得照抄外國體長數字；不得提供法律意見式結論；需維持政策文件風格。
  • 審閱問題：該章是否完成「事實→問題→原因→目標→選項→比較→建議→執行→評估」中的相應環節？是否有未證明跳躍？是否需要補來源或座談調查？
